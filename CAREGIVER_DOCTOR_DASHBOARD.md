# CCNER Caregiver & Doctor Dashboard Prototype

Branch: caregiver-doctor-dashboard

Open caregiver-dashboard.html for the standalone prototype. Use the role switch in the top-right to test both Caregiver and Doctor workspaces.

Included:
- Caregiver dashboard, patient profile, progress, cognitive activity, reminders/routine, medicines, appointments, care notes, wellbeing, safety, care team, reports, alerts, settings.
- Doctor dashboard, patient list, alerts, patient overview, cognitive activity, medications, assessments, clinical notes, care plan, reports, care team, patient timeline, settings.
- Patient timeline and change-since-last-visit concepts.
- Automatic observational insights and priority alerts.
- Client-side report export and print/PDF flow.
- Demo data persisted in localStorage for testing.

This is a UI/interaction prototype. Clinical/EHR integration, authenticated role permissions, real medication data, and server-side report generation should be connected before production use.
